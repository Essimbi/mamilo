# Questionnaire Contenus (version “copier-coller”) — Blog

## Mode d’emploi (pour le client)
- Parcourez le site page par page.
- Pour chaque champ ci-dessous, **collez le texte final exact** que vous souhaitez voir affiché.
- Si un champ doit être supprimé, écrivez : **[SUPPRIMER]**.
- Si un champ doit rester identique à la version actuelle, écrivez : **[OK TEL QUEL]**.
- Quand un champ a une contrainte, respectez-la (ex: longueur SEO).

## Conventions de format
- Les champs marqués **(H1/H2/H3)** sont des titres.
- Les champs marqués **(CTA)** sont des libellés de boutons/liens.
- Les champs marqués **(SEO)** servent au référencement.
- Si vous fournissez du texte pour un **contenu riche** (paragraphes, liens), précisez si vous voulez :
  - **Texte simple** (sans mise en forme)
  - **Texte avec mise en forme** (gras, liste, liens)
